# Peijie Ju — Academic Website

Personal academic website of Peijie Ju, PhD Candidate in Economics at the University of Bristol.

## Publishing

This repository is intended to be served by GitHub Pages from the `main` branch and the `/ (root)` directory. In repository **Settings → Pages**, select **Deploy from a branch**, **main**, and **/(root)**, then Save.

The website will use https://paigeju.github.io/ once GitHub Pages is enabled.

## Update

- Edit `index.html` to update research, teaching, and professional activities.
- Upload a headshot and academic CV PDF when ready to make these public, then update the image and CV link in `index.html`.
- Do not add dissertation chapter PDFs without checking that they are suitable for public release.
- `peijieju.com` requires separate domain registration and DNS setup before it can be used as a custom domain.
